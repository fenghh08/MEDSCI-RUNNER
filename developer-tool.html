Import from a spreadsheet 

        
Work in Google Sheets or Excel, then File → Download → CSV and paste the text here. Every row is checked before anything is added, and everything still lands in the Team queue for review. Nothing is ever deleted by an import.

      

      

        
        
        
        
      


      

        

          
Questions across any items or lectures

          
The most flexible import — course, topic and item are given per row. A blank questionId creates a new question; a matching one updates that question in place. If the item doesn't exist yet it is created for you (fill description/mechanism/funfacts on its first row to author it fully).

          
1 Export the current questions (or use the template sheet)  →  2 edit in a spreadsheet  →  3 paste the CSV below.

          

          

            
            

          

          
          

          

          
Column reference

            
ColumnRequiredNotes

              
questionIdnoBlank = new question. A real id (from the export) = update that question in place; its course/lecture/topic/item columns are then ignored so it can't be moved by accident.

              
course, topic, itemyesCourse code or name, topic id or name, item name. An unknown item is created.

              
lecturenoe.g. L12 — the lecture a newly created item is filed under. L01/l1 also work.

              
prompt, optionA–D, correct, explanationyescorrect is A, B, C or D.

              
hashtags, difficultynoSemicolon-separated tags; easy / medium / hard.

              
description, mechanism, funfactsnoFill in on a new item's first row to author it fully instead of a bare label.

Items (add or update in bulk) 

          
Export every item, edit in a spreadsheet, paste back. A row with an existing itemId updates that item (questions untouched); a blank itemId creates a new one. On an update row, a blank cell means "leave as is".

          

          
          

          

          
Column reference

            
ColumnRequiredNotes

              
label, descriptionyesAlways required, even on an update row.

              
itemIdnoBlank = new item. Only ever paste an id the export gave you.

              
theme, topicnew rowsCourse id and topic id the new item goes under. Ignored on update rows.

              
mechanism, funFacts, activeRecall, hashtagsnoLists are semicolon-separated.

              
course, classnoMust match an existing course code and lecture key.

              
images, refsnocaption|url;caption2|url2 and label|url;label2|url2.

            

          

        

      


      

        

          
Learning outcomes for many lectures

          
Export every lecture, fill in the outcomes / intro columns, paste back. Only existing lectures can be edited this way; a row with blank outcomes is skipped.

          

          
          

          

        

      

    


    
    

      

        
Team queue 

        
Everything anyone adds — here or from inside the game (suggestions, reports) — shows up for the whole team in real time. Open a row to read exactly what was submitted. Once the maintainer has merged something, remove it here.

🧬 Merge the queue into game-data.js 

          
Takes everything in the queue and folds it into a complete copy of the data file. You then replace game-data.js with it. Player reports are skipped (they're for reading, not merging).

          

          

            

            

              
              
              
            

            
Only remove entries after the new file is saved over game-data.js and pushed. This removes exactly what this merge included, nothing added since.

          

          
Merge template — refresh if GAME_CONFIG, STAGES or comments were hand-edited i

            
The merge only rebuilds COURSES and THEMES; everything else is carried through from a template. The built-in template matches the file as of this tool's release. Refresh it after hand-editing the other sections.
