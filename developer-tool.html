Fill in the fields below — no code needed. This generates ready-to-paste code in the exact format the Runner Game uses, and adds it straight to the shared queue below — nothing to copy or send anywhere.

How this works

  1. Type your name below (so Eason knows who submitted what).
  2. Pick a tab: New Item (a study guide entry), New Question, or New Course (a whole new subject area).
  3. Fill in the fields. A code preview updates live on the right — you don't need to understand it, just check the fields look right.
  4. Click "Add to batch". It's saved straight to the shared Team Queue below — synced live, so Eason (and everyone else) can already see it. Repeat for as many items/questions as you want to contribute. If you added any image/icon files, upload them to the shared Drive folder linked below, named exactly as shown.
  5. That's it — you don't need to copy, download, or send anything to Eason. He reviews and merges straight from the queue. ("Copy entire queue" / "Download as .txt" are just there if you want a personal record of what you added, or as a fallback if the queue can't sync for some reason.)
Used only to credit you in the batch you send — doesn't affect any IDs or filenames.

📄 Bulk-add questions from CSV — for one existing item at a time

      
Pick the item these questions belong to, then paste CSV text (with a header row) covering just the question fields — course/topic/item are already fixed by your pick above, so the CSV doesn't need to repeat them. 📄 Add questions by lecture — mixed courses/topics/items in one paste

      
For a whole lecture's worth of questions at once, even when they land on different items, topics, or courses — course/topic/item are given per row instead of picked once. If a row's item doesn't already exist, it's created automatically as a placeholder (just the label — no description yet) so the question has somewhere to attach; it'll show up flagged as incomplete until someone fills the rest in later. A row's lecture column (e.g. L12) sets that specific lecture as the citation for any new item it creates — leave it blank to fall back to the Course & class default below instead.

      
Prefer a spreadsheet? The question-adding template sheet works here too — just add four columns at the start (course, lecture, topic, item) before the existing ones, fill those in per row, then export and paste as usual.
